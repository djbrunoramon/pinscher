# Security Policy

## Supported versions

Only the latest released version of Pinscher receives security fixes.

## Report a vulnerability

Use GitHub's private vulnerability reporting: open the repository's **Security** tab and select **Report a vulnerability**. Do not report security issues in public issues.

The maintainer will make a best effort to acknowledge reports and provide an initial response within 7 days.

## Scope

Reports are especially welcome for issues involving app permissions, synthetic input events, or captures of menu bar items. Please include the affected version, macOS version, impact, and steps to reproduce. Do not include personal data or captured images unless the private report flow requires relevant evidence; redact unrelated information.
