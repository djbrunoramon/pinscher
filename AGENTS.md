# AGENTS.md

Instructions for AI coding agents (and humans) working on Pinscher.

## What this is

Pinscher is a macOS menu bar manager written in Rust. It talks to AppKit directly through the
`objc2` crates; there is no Swift, no webview and no cross-platform UI layer. Minimum macOS is 14.

## Commands

| Task | Command |
|---|---|
| Build (debug) | `cargo build` |
| Run from source | `cargo run` (logs to stderr; set `PINSCHER_LOG=debug` for more) |
| Tests | `cargo test` |
| Lint | `cargo clippy --all-targets -- -D warnings` |
| Format | `cargo fmt` (CI runs `cargo fmt --check`) |
| App bundle | `./scripts/bundle.sh` (universal `dist/Pinscher.app`, ad-hoc signed) |
| Read unified logs | `/usr/bin/log stream --level info --predicate 'subsystem == "io.github.djbrunoramon.pinscher"'` |

The toolchain is pinned in `rust-toolchain.toml`; rustup installs it on first use.

## Layout and rules

- `src/core/`: pure logic. **No AppKit, CoreGraphics or other macOS calls here.** Every module has
  unit tests in a `#[cfg(test)] mod tests` block at the bottom of the same file.
- `src/platform/`: thin adapters over macOS APIs. They translate between macOS types and `core`
  types and hold no decisions. Anything that needs a decision goes to `core` first.
- `src/app.rs`: the `AppDelegate`; wires platform events to core and core outcomes to platform.
- One concern per file. Do not add new layers, generic helpers or traits "for later".
- `unsafe` blocks always carry a `// SAFETY:` comment.
- Never log user paths, other apps' names, captured images or config values. Log keys and error kinds.
- User-facing strings go through `core::l10n` (English and Brazilian Portuguese). Never hard-code UI text.
- New dependencies need a reason in the PR description and must be checked on crates.io first.

## Reference files (copy their shape)

| Kind | Reference |
|---|---|
| Pure core module with tests | `src/core/config.rs` |
| Platform adapter | `src/platform/status_bar.rs` |
| AppKit window/controller | `src/platform/preferences.rs` |
| Localized strings | `src/core/l10n.rs` |

## Commits

Conventional Commits (`feat:`, `fix:`, `docs:`, `chore:`, `ci:`, `refactor:`, `test:`). Small, focused
commits. Do not add AI co-author or "generated by" trailers.
